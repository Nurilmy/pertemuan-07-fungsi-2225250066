## Tujuan
Menggunakan fungsi, parameter, return value, dan scope untuk membuat program modular.

## Struktur Fungsi
- salam(nama): menampilkan salam berdasarkan nama.
- luas_persegi_panjang(p, l): menghitung luas persegi panjang.
- jumlah_n(n): menghitung jumlah bilangan dari 1 sampai n.
- statistik(data): menghitung nilai minimum, maksimum, dan rata-rata.
- demo(x): menunjukkan local scope dan global scope.
- luas_segitiga(a, t): menghitung luas segitiga.
- faktorial(n): menghitung faktorial.
- tampilkan_menu(): menampilkan menu operasi matematika.

## Cara Menjalankan
